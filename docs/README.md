# Recommender Bias Propagation — Documentation Hub

Welcome to the documentation and research repository for **Closed-Loop Recommender Bias Propagation and Latent Manifold Dynamics**.

This directory houses all experimental benchmarks, theoretical research notes, academic assets, publication-quality figures, and reference literature.
