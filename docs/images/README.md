### 5. Phase 5: LightGCN — Graph-Powered Bias Amplification ([`phase_5_lightgcn/`](./phase_5_lightgcn/))
* **Notebook**: [`notebooks/phase_5_lightgcn.ipynb`](../../notebooks/phase_5_lightgcn.ipynb)
* **Comparative Cross-Model Dashboard**:
  * `benchmark_trajectories_lightgcn.png`: 4-tier benchmark metric trajectories ($G$, $D_{\text{KL}}$, $NDCG@10$, $S_{\text{eff}}$) comparing all 5 models (MF, PMF, BPR, MostPop, LightGCN) across 50 generations ($t=0 \dots 49$) with clean unified bottom legend.
* **LightGCN-Specific Assets (50 Generations: $t=0 \dots 49$)**:
  * `tsne_popularity_drift.png`: Joint 2D t-SNE manifold showing graph-structural popular item attractor consolidation ($t=0$ vs $t=49$), with red (top-30 short-tail) and blue (bottom-30 long-tail) displacement vectors and isolated right-margin colorbar.
  * `tsne_genre_clusters.png`: Genre boundary homogenisation driven by co-click graph propagation ($t=0$ vs $t=49$).
  * `tsne_manifold_density.png`: KDE density compression showing LightGCN's severe, multi-lobed density contraction at $t=49$.
  * `embedding_drift_trajectory.gif`: **50-frame animated GIF** (1 frame per real generation $t=0 \dots 49$) tracking graph-powered popular item clustering alongside live Gini and Effective Rank.
  * `quantitative_embedding_drift_trajectory.gif`: **50-frame animated GIF** of 32-D Euclidean drift, Cosine distance, and Vector Norm across popularity tiers, demonstrating the $5.07\times$ Short-tail vs. Long-tail Euclidean drift disparity ($1.272$ vs. $0.251$).
* **Key Takeaway**: Demonstrates the *Illusion of Personalization* in Graph Neural Networks—multi-hop graph convolution collapses macro recommendation behavior toward MostPop while compressing latent manifold effective rank. Generated by `scripts/generate_simulation_visuals.py` (trajectory assets) and `scripts/plot_results.py` (cross-model dashboard).

### 6. Phase 6: LightFM — Pairwise Ranking & WARP Loss Dynamics ([`phase_6_lightfm/`](./phase_6_lightfm/))
* **Notebook**: [`notebooks/phase_6_lightfm.ipynb`](../../notebooks/phase_6_lightfm.ipynb)
* **Research Note**: [`docs/notes/phase6_lightfm.md`](../notes/phase6_lightfm.md)
* **Visuals & Dynamic Assets**:
  * `benchmark_trajectories.png`: 4-tier diagnostic trajectory dashboard comparing LightFM (WARP) vs. LightFM (BPR) across 50 generations with $\pm 1\sigma$ error bands.
  * `tsne_popularity_drift.png`: Joint 2D t-SNE space ($t=0$ vs $t=49$) with red displacement arrows tracking top-50 popular movies.
  * `tsne_genre_clusters.png`: Genre cluster projections showing spatial preservation of 8 primary movie genres.
  * `tsne_manifold_density.png`: 2D KDE contour map comparing initial factor dispersion ($t=0$) to post-feedback density ($t=49$).
  * `embedding_drift_trajectory.gif`: 50-frame animated GIF tracking 2D embedding movement alongside live Catalog Gini and Effective Rank metrics.
  * `quantitative_embedding_drift_trajectory.gif`: Synchronized dual-panel animation tracking 2D latent PCA movement alongside live 32-D quantitative drift metrics (Euclidean, Cosine, Vector Norm) stratified across Short-tail, Mid-tail, and Long-tail cohorts.
* **Key Takeaway**: Tests whether WARP loss slows runaway bias propagation relative to BPR. Phase 6 is a supplementary run using the repository's native LightFM fallback; see the Phase 6 note for current numbers and caveats.
